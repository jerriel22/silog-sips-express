# Silog & Sips Express

Affordable Filipino silog meals and refreshing drinks for students, packaged for quick pick-up. This is an interactive business website built with **PyScript** for our Event-Driven Programming final project at Cebu Eastern College.

## Business Concept

Silog & Sips Express sells budget-friendly, ready-to-eat silog rice bowls (Tocilog, Tapsilog, Hamsilog/Chicksilog, Bangsilog) with local drinks like Sago't Gulaman and Samalamig. Students pre-order on the website, so they can pick up their meals at a campus booth without waiting in long queues.

## Features

- **Pre-order form** (`order.py`): choose a meal, drink, and quantity, then see a live order list and total.
- **Budget checker** (`budget.py`): type your allowance and instantly see how many combos you can afford.
- **Customer feedback** (`feedback.py`): submit a rating and comment, and see the average rating update.

## Event-Driven Programming

The website uses PyScript to respond to user events:

- `click` events on the "Add to order", "Place order", and "Send feedback" buttons
- `input` events on the allowance field, which update the result as the user types
- Dynamic page updates, where the order list, total, and feedback list change without reloading the page
